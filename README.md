# Online Java Quiz

Minimal Spring Boot application that serves an online Java quiz using Thymeleaf.

How to run
1. Ensure JDK 17+ and Maven are installed.
2. From the project root:
   mvn spring-boot:run
3. Open http://localhost:8080

Project structure
- src/main/java/com/example/quiz - application code
- src/main/resources/templates - Thymeleaf templates
- pom.xml - Maven config
